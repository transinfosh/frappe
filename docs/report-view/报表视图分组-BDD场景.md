# 报表视图分组 BDD 场景

| 编号 | Given / When | Then |
| --- | --- | --- |
| G01 | 已有未指定 mode 的汇总报表被打开 | 按旧汇总方式显示，统计结果保持一致 |
| G02 | 用户按主表字段启用明细分组 | 显示分组标题、计数、小计以及真实明细 |
| G03 | 当前仅加载一条，分组有三条数值 10、20、30 | 进度显示 1/3，小计为 60 |
| G04 | 用户折叠一组或全部组，再展开 | 小计与组标题保留，明细按展开状态显示，批量选择不漂移 |
| G05 | 尚有未加载的组内记录，点击加载更多 | 按相同筛选条件与组值分页加载，不重复显示记录 |
| G06 | 修改全局筛选条件或刷新 | 小计、数量与明细同步更新，旧异步请求不覆盖新结果 |
| G07 | 子表筛选匹配同一主表记录多次 | 主表计数与数值合计不被重复放大 |
| G08 | 无主表读取权限或使用外部 DocType 分组字段 | 拒绝查询，不泄露分组信息 |
| G09 | 选择子表列或虚拟 DocType 明细分组 | 清楚提示不支持，不返回具有歧义的统计 |
| G10 | 同一组含多种币种 | 不将其金额直接相加，显示混合币种提示 |
| G11 | 勾选或导出展开后的真实记录 | 索引映射到真实记录，不将组标题作为业务对象 |
| G12 | 保存、刷新、分享 URL 并切换两种模式 | 恢复相应模式，旧链接仍使用汇总模式 |
| G13 | 分别在英文与中文环境查看控件和小计 | 显示对应语言文案，插值与选项标签正确 |
| G14 | 清除分组或筛选后没有记录 | 恢复标准表格或显示空结果，不能残留旧数据 |
| G15 | 分组值为空或含 HTML 字符 | 正确隔离空值分组，文本安全显示，不执行 HTML |
| G16 | 按供应商、仓库两级分组且仅加载部分记录 | 每一级均显示完整范围的小计，明细只在末级展示 |
| G17 | 将仓库上移至第一级 | 重建仓库→供应商层级，统计与保存配置按新顺序生效 |
| G18 | 不同供应商下有同名仓库，折叠或加载其中一个 | 仅影响完整路径对应的节点，不影响另一父级的同名节点 |
| G19 | 增加第三级、移除一级或选择重复字段 | 支持增删层级，重复字段不可选且服务端拒绝 |
| G20 | 保存多级设置后刷新或分享 URL | 恢复有序字段及相同层级；旧单字段设置仍恢复为一级 |
| G21 | 组内加载请求发出后调整分组顺序 | 旧响应不得写入新分组树或缓存 |
| G22 | 存在多级分组标题及小计行 | 这些展示行的序号为空，只有末级明细编号 |
| G23 | 每组含多条记录，加载更多或折叠其他组 | 每组从 1 连续编号，新增明细接续，其他组的折叠不改变编号 |
| G24 | 打开明细或汇总分组设置面板 | 保留必要标签与操作，所有说明段落均移除 |
| G25 | 无数值小计的多级分组 | 标题横跨全部数据列，ID 列保持正常宽度，折叠与加载可用 |
| G26 | 分组包含数量或金额小计 | 标题区域合并，小计与明细的对应数值列对齐 |
| G27 | 调整列宽、横向滚动或切回普通视图 | 合并标题随列宽和滚动同步，普通表格列布局不受影响 |
| G28 | 查看分组行与真实明细 | 分组标题从行号列起合并，小计仍对齐；明细行号表头为 #，组内编号保持连续 |
| G29 | 未分组、汇总分组、多字段明细分组三种状态 | 入口分别显示分组、汇总分组、明细分组加字段数徽标，不展示字段列表 |
| G30 | 重载已保存分组后直接点击清除，或清除汇总分组 | 无须打开设置，恢复普通明细并移除缓存、聚合列及已保存分组 |
| G31 | 使用分组入口与末尾清除按钮之间的切换按钮 | 全部折叠和展开交替执行，提示随动作切换，无独立工具栏或说明文字 |
| G32 | 明细模式打开任意数据列表头菜单 | 保留升序、降序、重置排序、移除列、冻结/解冻和添加列；排序通过服务端重查，不将组标题混入明细；增删/重排列后序号、完整路径和合并标题仍正确，ID 不可删除 |
