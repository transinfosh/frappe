# 报表视图分组规格契约

## 范围与设计

责任应用为 Frappe，适用于 Report Builder 的标准 Report View，供所有业务 app 复用。不涉及 Query Report、Script Report 或 List View。统一分组入口提供互斥的 `summary`（汇总分组）与 `detail`（明细分组）模式。

- 筛选栏分组入口在未启用时显示“分组”，汇总模式显示“汇总分组”，明细模式显示“明细分组”加字段数徽标，不在按钮上列出字段名称。分组按钮组最右侧提供清除按钮；明细模式在分组入口与清除按钮之间提供一个全部展开/折叠切换按钮，三个按钮等高并垂直居中，悬停提示当前动作。明细配置在“显示方式”下方提供加粗的“字段明细”标题，各行左侧仅显示从 1 开始的顺序号，包含各级字段和增删、排序操作；字段选择框仍保留本地化层级名称供辅助技术使用。汇总配置分别标注“分组字段”“汇总方式”，需要指定数值列时标注“汇总字段”。表格上方不再单独显示展开/折叠工具栏或说明文字。清除必须支持尚未打开设置面板的已保存配置，移除分组状态、缓存和聚合列并保存为普通明细视图。
- 汇总模式沿用现有分组字段、计数、求和、平均值查询，每组一行。
- 明细模式保留主表记录，支持按有序字段列表进行多级分组、逐组及全部展开/折叠、末级组内分页加载。字段可添加、移除、上移和下移；顺序决定第一、第二级及后续层级。分组标题显示已加载数/总数。
- 服务端根据当前筛选条件和用户权限，在分页前计算每组记录数及可见数值列的小计。主表记录经去重后统计，关联子表筛选不应放大总数或金额。
- 小计自动包含 Int、Float、Currency、Duration 列；Check、Percent、其他类型不求和。币种字段来自本单据字段且组内币种不一致或缺失时，金额小计不展示数值。任意数量列的单位一致性由报表选列与分组条件保证，框架不推断业务单位。
- 明细模式第一版只支持主表字段，拒绝子表列及虚拟 DocType。保留表头列下拉菜单及列顺序调整；列菜单升序、降序和重置排序同步标准排序选择器并重新查询真实记录，禁止对含标题的展示行本地混排。增删列及重排列顺序通过报表字段重建分组行和小计；ID 列仍不可删除。冻结/解冻沿用 DataTable 列能力，分组标题继续横向滚动，数值小计与对应列保持一致。明细模式新增列仅提供主表字段，行内筛选继续关闭，筛选通过标准筛选栏完成。
- 明细分组只对真实记录显示序号；分组标题与小计行序号留空。每个末级分组从 1 开始，组内加载更多时连续编号，折叠其他组不改变本组序号。该显示编号不改变业务记录名称、选择映射或导出数据。
- 分组设置面板仅保留显示方式、分组字段标签及操作按钮，不展示模式说明或层级使用说明段落。
- 分组标题跨数据列显示：无数值小计时合并全部数据列，有小计时合并首个小计列之前的标题区域，小计仍与对应列对齐；行号列也并入分组标题，仅保留独立的勾选区域；真实明细仍保留行号列，Report View 行号表头统一使用 `#`。不为分组标题强制加宽 ID 列，保留用户设置的列宽。合并区域随列宽调整和横向滚动同步。
- 分组标题是展示行，不是业务记录；不得被编辑或作为批量操作目标。记录行保留原有链接和批量操作，明细分组内禁用行内编辑，通过记录链接进入表单修改；实时更新后重新查询小计，折叠/重绘清除旧勾选，防止行索引漂移。
- 导出与打印沿用明细记录语义，不输出交互式分组标题；当前可见明细按实际映射导出，导出全部走原有完整查询。分组小计在页面展示，不宣称已有分组格式的导出或打印。

## 数据与接口

无需 DocType 或 schema 变更。保存的 `group_by` 配置增加可选 `mode`，缺省为 `summary`；旧报表与用户设置继续按原汇总模式恢复。URL 的 `_group_by` 数组增加可选第四项模式，旧三项链接仍有效。明细模式增加 `group_by_fields` 有序数组；旧单字段配置自动视为一级。URL 数组第五项为有序字段列表，旧四项链接仍有效。

现有 `frappe.desk.reportview.get` 增加可选 `detail_group_by` 请求参数（主表字段表达式或有序表达式数组，兼容原单字段字符串），仅启用时在压缩响应中追加 `detail_groups`，包含兼容的 `fieldname` 以及 `fieldnames`、`sum_fields`、`groups`；多级节点额外包含 `_level` 和完整祖先路径 `_path`。原 `keys`、`values`、`user_info` 不变。组内加载沿用标准查询及权限校验。其他查询与导出忽略该展示参数。

不得从浏览器接受忽略权限或任意聚合表达式。字段必须属于本主表、真实存在、具有读取权限且未被 report_hide 隐藏。小计只使用经过权限检查的列。无读权限时拒绝查询，不泄露分组信息。

## 实现与边界

当前实现及验证状态见[测试映射](报表视图分组-测试映射.md)。暂不支持子表明细分组、跨单位自动换算或保留分组格式的导出。展开全部只展开已加载明细，其余通过每组“加载更多”获取，界面明确标出加载进度。

## 多级分组规则

- 每一级小计均由相同权限与筛选条件的去重主表记录直接聚合，不能通过已加载明细求和，也不能通过子组金额相加推断父级币种。
- 节点以完整祖先路径识别。同名子组在不同父级下独立折叠、加载和显示小计。
- 末级加载必须同时包含所有祖先字段条件；上级展示完整子组结构及已加载数，不直接混入明细行。
- 折叠上级时隐藏全部后代，重新展开保留子组折叠状态；全部展开/折叠作用于所有节点。
- 调整顺序、增删字段后重新查询，清空旧缓存与折叠状态，使先前异步加载失效。
- 各级字段均检查所属主表、字段读取权限、隐藏/虚拟属性与脱敏限制，不允许重复字段。分组字段自身不重复参与数值小计，以免覆盖节点标识。
